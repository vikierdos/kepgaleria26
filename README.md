# British Monarchs Gallery

An interactive Victorian-themed portrait gallery built with React, TypeScript, and Vite.

## GitHub Pages

After deployment, the website will be available at:

**https://vikierdos.github.io/kepgaleria26/**

### Publish the website

1. Push this project to the `main` branch of `https://github.com/vikierdos/kepgaleria26`.
2. Open the repository on GitHub.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, set **Source** to **GitHub Actions**.
5. Open the **Actions** tab and wait for the `Deploy to GitHub Pages` workflow to finish.

Every later push to `main` will update the website automatically.

npm run dev
